# Муми-тролль: Подарки для Фрекен Снорк

Небольшой браузерный платформер на чистом JavaScript с использованием Canvas. 
Сюжет: Муми-тролль собирает подарки (бабочку и сердечки), прыгает по платформам, избегает шипов и добирается до Фрекен Снорк.

## Управление
* **← →** или **A / D** — движение влево/вправо
* **Space** или **W** (или **↑**) — прыжок
* Для мобильных устройств предусмотрены экранные кнопки.
* В правом верхнем углу находится кнопка настроек (⚙️), где можно настроить громкость, включить/выключить музыку и сбросить рекорд.

## Запуск
Для запуска игры требуется локальный HTTP-сервер (так как используются ES-модули).
1. Откройте папку с проектом в VS Code.
2. Запустите **Live Server** (или выполните в терминале `python -m http.server 8000`).
3. Перейдите по адресу `http://localhost:8000` (или `http://127.0.0.1:5500` в Live Server).

## Технологии и структура
* HTML5 / CSS3
* Vanilla JavaScript (ES-модули)
* Canvas API для отрисовки графики и физики
* `localStorage` для сохранения рекорда времени
* Без использования сторонних игровых движков и сборщиков.

**Структура файлов:**
* `index.html` — разметка, меню, настройки, аудио-теги
* `style.css` — пастельное оформление, адаптивность
* `js/main.js` — игровой цикл, обработка кнопок и звуков
* `js/Game.js` — логика уровней, отрисовка фона, платформ и предметов
* `js/Player.js` — физика персонажа (гравитация, прыжки, коллизии)
* `js/input.js` — обработка нажатий клавиатуры
* `js/collision.js` — проверка пересечений (AABB)
* `assets/` — папка с картинками и звуками

## Использование нейросети
При разработке игры использовалась нейросеть (DeepSeek) для генерации кода, физики и отладки.

**Примеры промптов:**
1. «Создай небольшой платформер на HTML/CSS/ванильном JS с Canvas. Нужны index.html, style.css, ES-модули main.js, Game.js, Player.js...»
2. «Добавь Player: движение стрелками или A/D, прыжок Space/W, гравитацию. Скорость измеряй в пикселях в секунду, обновление принимает dt.»
3. «Добавь первый проходимый уровень с пятью платформами. Реализуй столкновения сверху, сбоку и снизу...»
4. «В игре проблема: герой проваливается сквозь платформу. Найди причину и исправь её, сохрани дизайн и правила игры.»
